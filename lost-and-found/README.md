# 學務處失物招領系統

學生不用登入就能查詢拾獲物品，處室人員登入後可以登記、認領、處置物品。
網頁放在 GitHub Pages，資料存放在學校自己的 Google 試算表，照片存放在 Google 雲端硬碟。

```
lost-and-found/
├── index.html          網頁
├── app.js              網頁程式
├── styles.css          樣式
├── config.js           ← 只需要改這個檔：填入 Apps Script 網址
└── apps-script/
    └── Code.gs         ← 貼到 Google Apps Script 的後端程式
```

## 帳號密碼怎麼運作？

| 身分 | 需要登入嗎 | 可以做什麼 |
|---|---|---|
| 學生 / 訪客 | 不用 | 瀏覽招領公告、搜尋、看統計 |
| 處室人員 | 要 | 登記拾獲、登記認領、逾期處置、編輯、匯出清冊、改自己的密碼 |
| 管理者 | 要 | 以上全部，再加上刪除物品、修改系統設定、新增或刪除帳號、重設密碼 |

- 密碼經過加鹽雜湊後存在試算表的隱藏工作表「帳號」，網頁原始碼裡沒有任何密碼。
- 帳號驗證在 Google 的伺服器上進行。沒有登入的人透過 API 也只拿得到公開欄位，拿不到拾獲人、辨識特徵、認領人個資。
- 登入 6 小時沒有操作會自動登出。同一帳號連續輸錯 5 次會鎖定 10 分鐘。

## 一、建立 Google 後端（約 10 分鐘，只需做一次）

1. 用學校的 Google 帳號（建議用處室的公務帳號）建立一份**新的 Google 試算表**，例如命名為「失物招領資料庫」。
2. 在試算表上方選單點 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，把 [`apps-script/Code.gs`](apps-script/Code.gs) 的全部內容貼上，按 💾 儲存。
4. 在上方函式選單選 **`setup`**，按 **▶ 執行**。
   - 第一次執行會要求授權，按「審查權限」→ 選擇帳號 →「進階」→「前往（不安全）」→「允許」。
     （這是你自己寫的程式，所以 Google 會顯示未驗證的警告。）
5. 執行完成後，打開下方的**執行記錄**，會看到：
   ```
   管理者帳號：admin
   臨時密碼：xxxxxxxxxx
   ```
   **請抄下這組密碼**，第一次登入網站時要用。
6. 點右上角 **部署 → 新增部署作業**：
   - 齒輪 ⚙ → 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學生不用登入 Google 也能查詢；處室功能另外由帳號密碼保護）
   - 按「部署」，複製 **網頁應用程式網址**（以 `/exec` 結尾）。

## 二、把網址填進網站

1. 在 GitHub 打開 `lost-and-found/config.js`，按右上角的 ✏️ 編輯。
2. 把網址貼進引號裡：
   ```js
   window.LF_CONFIG = {
     apiUrl: 'https://script.google.com/macros/s/AKfy.../exec',
   };
   ```
3. 按 **Commit changes** 儲存。

## 三、開啟 GitHub Pages（只需做一次）

1. 到這個儲存庫的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 Save。
3. 等 1～2 分鐘，網址就是：
   **https://csps343601.github.io/WebSite/lost-and-found/**

## 四、第一次登入

1. 打開網站，按右上角「處室人員登入」，輸入 `admin` 和步驟一抄下的臨時密碼。
2. 到「設定」→ **變更我的密碼**。
3. 在「帳號管理」替生輔組同仁建立帳號（會產生臨時密碼，交給同仁登入後自行修改）。
4. 在「系統設定」修改處室名稱、服務時間、保管期限、常用地點。

## 常見問題

**忘記密碼怎麼辦？**
請管理者到「設定 → 帳號管理」按「重設密碼」。
如果連管理者都忘了密碼：打開 Google 試算表，上方選單 **失物招領 → 重設帳號密碼…**，輸入 `admin`。

**照片在網站上顯示不出來？**
照片存在試算表擁有者的雲端硬碟「失物招領照片」資料夾。如果學校的 Google Workspace 禁止「知道連結的任何人」分享，照片會存起來，但網站上看不到。請資訊組開放對外分享，或改用個人 Google 帳號建立後端。

**修改了 Code.gs 之後？**
到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址會維持不變。

**可以直接在試算表改資料嗎？**
可以。「物品清冊」工作表的每一列就是一件物品，修改後網站約 1 分鐘內就會更新。請不要更動第一列的標題和 ID 欄。

**還沒設定後端前可以試用嗎？**
可以。`config.js` 的 `apiUrl` 留空時，網站會進入「展示模式」：輸入任意帳號密碼就能登入，所有功能都能試用，但重新整理後資料會消失。
